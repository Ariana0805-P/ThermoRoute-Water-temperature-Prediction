# Output Status

This repository includes the result products needed to inspect and audit the
manuscript's conventional held-out benchmark summaries.

- `conventional/` contains held-out 2021-2023 metric tables, station summaries,
  probability summaries, paired effects, and validation records.

The complete `outputs/final/` Parquet products, key registries, frozen model
weights, training caches, and large prediction caches are not included in this
public repository. They can be archived separately if full processed-data
release or exact frozen-inference replay is required.
